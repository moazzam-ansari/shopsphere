# ShopSphere Architecture

Shopsphere is a distributed e-commerce platform that will be developed using a microservices architecture.

## Current Services

The first service implemented is Product Service.

## Product Service

Product Service is responsible for managing products.

Responsibilities:

- Create product
- Get product
- Update product
- Delete product

## Technology Stack

- Java
- Spring Boot
- Spring Data JPA
- Hibernate
- MySQL
- Maven
- REST APIs

## Request Flow

Client
↓
API Gateway
↓
Product Service
↓
MySQL
